# Grade comparison investigation

## Evidence

- The [official BilimClass mobile guide](https://help.bilimland.kz/l_rus/knowledge_base/item/356645) describes lesson grades, subject history and predicted grades. It does not document grade comparison, its data source or its calculation.
- MaterialClass currently opens a placeholder from `GradeTile` in `app/src/main/java/org/materialclass/ui/GradesScreens.kt`. It states that classmates' grades are unavailable and makes no comparison request.
- The existing grade pipeline combines the subjects response with the current student's journal records by schedule UUID. The journal request is scoped to the current user and student groups. It does not establish an API contract for classmates' grades or aggregate comparison statistics.
- Static string inventory of the user-supplied BilimClass APK set, SHA-256 `d995f8fc400825776f2a19ec301b21e1c7ea9f16cc56a96cc14f9694737a1e20`, identifies an ARM64 Flutter `libapp.so` containing `api/mobile/comparison/classroom/lesson`, `fetchComparisonInfo`, `ComparisonRepository`, `ComparisonInfo`, `StudentMark`, `ClassmatesMark` and `_ComparisonDiagram`. The archive identifies package `com.bilimland.bilimclass` and version code 117. These are literal strings, not observed network traffic or reconstructed call sites.
- An authorized read-only probe using one student account and a web-login access token returned HTTP 422 JSON for `GET https://api.bilimclass.kz/api/mobile/comparison/classroom/lesson` without query parameters. The response had root keys `errors` and `message`; the validation errors named both `uuid` and `type` as required. A prior sanitized probe on 2026-11-13 independently recorded the same host, method and status. This confirms only a validation response in those contexts, not that the APK uses this host, token, method, or query structure.
- The supplied prototype's `components.js` shows a ten-row distribution and a highlighted own grade, but derives it from generated preview data and replaces zero counts with one. This is a design mock, not evidence of the upstream calculation or API.

## Unknowns and next steps

The valid meaning and allowed values of `uuid` and `type`, the upstream application's actual request, successful response shape, and access rules remain unverified. The `ClassmatesMark` and `StudentMark` names suggest a comparison involving the student and classmates, but do not establish the actual data or presentation. Do not guess parameter values, expose other students' data, or fabricate statistics from the current student's grades. Inspect an authorized upstream app session or reconstruct the actual call site and collect only sanitized request and response schema evidence before implementing this feature. A successful observation for one account does not establish access for other roles or schools.
