# Toolchain and dependency status

This is a test-only scaffold, not a release. Material 3 Expressive requires the explicit `androidx.compose.material3:material3:1.5.0-beta02` override; beta APIs and compatibility can change and Google does not recommend beta releases for production. The resolved dependency graph and compatibility are not yet established.

- AGP 9.3.1, Kotlin and Compose compiler 2.4.21, Gradle 9.5.0, JDK 21: [Kotlin compatibility](https://kotlinlang.org/docs/gradle-configure-project.html), [AGP notes](https://developer.android.com/build/releases/agp-9-3-0-release-notes), [built-in Kotlin](https://developer.android.com/build/migrate-to-built-in-kotlin).
- Compose BOM 2026.09.00, Material3 1.5.0-beta02, Activity Compose 1.13.0: [BOM](https://dl.google.com/dl/android/maven2/androidx/compose/compose-bom/2026.09.00/compose-bom-2026.09.00.pom), [Material3 releases](https://developer.android.com/jetpack/androidx/releases/compose-material3), [Activity POM](https://dl.google.com/dl/android/maven2/androidx/activity/activity-compose/1.13.0/activity-compose-1.13.0.pom).
- Test dependencies: JUnit 4.13.2, AndroidX test runner 1.7.0 and AndroidX JUnit 1.3.0. [JUnit](https://repo.maven.apache.org/maven2/junit/junit/4.13.2/junit-4.13.2.pom), [runner](https://dl.google.com/dl/android/maven2/androidx/test/runner/1.7.0/runner-1.7.0.pom), [AndroidX JUnit](https://dl.google.com/dl/android/maven2/androidx/test/ext/junit/1.3.0/junit-1.3.0.pom).
- Compile SDK 37 follows Compose UI requirements; target SDK 37 is tentative and requires behavioral review. minSdk 24 is tentative: the Material3 beta AAR declares 24, but the full resolved graph, merged manifest and device execution remain to be checked. [Compose UI](https://developer.android.com/jetpack/androidx/releases/compose-ui).
- The Gradle distribution checksum is pinned in wrapper properties; the wrapper JAR matches the [official checksum](https://services.gradle.org/distributions/gradle-9.5.0-wrapper.jar.sha256).
- AndroidX POMs identify Apache-2.0; this is not a complete SPDX/license or NOTICE audit of resolved direct and transitive build, runtime and test dependencies. The GPL compatibility and release gate remain blocked pending that audit.
- HTTP, serialization, encrypted storage, backups, real service contracts and no-GApps product behavior are not implemented or verified. There is no server adapter or real account data in this scaffold.
